NAMING BOUNDARIES
-----------------
Synq.ai is the repository and product. Lecture Lens, Master Pedagogy,
Synq Extension, Synq Workspace, Synq Mastery, and Code Bar are product
modules. The technical tree should preserve these names in user-facing
copy while keeping implementation boundaries explicit.

INITIAL IMPLEMENTATION BOUNDARY
--------------------------------
The first build should prioritize the Tauri desktop shell, Synq Workspace,
Lecture Lens ingestion, Master Pedagogy notebook generation, Supabase sync,
managed cloud provider routing, and optional ElevenLabs audio recaps. Synq Mastery and
Code Bar should begin with usable foundational flows. Synq Extension should
be developed after the ingestion contract is stable.
